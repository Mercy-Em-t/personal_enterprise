# Tryphen Emurugat V2 Enterprise (2050 Architecture)

This is the core monolithic application powering the Tryphen Emurugat Enterprise operations. Built on Next.js 15 (App Router), this application is designed not just as a client portal, but as a fully automated, agent-driven orchestration layer.

## 🏗️ Core Architecture Overview

The system is built on a **Zero-Trust, Multi-Tenant Sieve Architecture**. It is designed to aggressively qualify incoming leads, sanitize file uploads, and automatically generate $1M+ Statements of Work (SOWs) without manual intervention.

### 1. The 3-Path Sieve Routing
Leads are filtered through a 3-step routing process to ensure only high-intent, qualified clients reach the Admin OS.
- **`/s/[id]` (Service Detail Hub):** The public landing page showcasing a specific service capability.
- **`/a/[id]` (The AI Solutions Architect):** An interactive, dynamic AI chat portal where the lead is interrogated about their budget, constraints, and architecture needs.
- **`/q/[id]` (The Curated Intake & KYC):** The final step where qualified leads lock in their contact details. Includes the Zero-Trust Drag-and-Drop file ingestion zone.

### 2. The Council of Agents (Micro-Agent Backend)
Instead of a single monolithic AI, the backend is operated by four specialized, autonomous agents communicating via API routes:
- **`POST /api/agents/sentinel` (Agent 00 - The Sentinel):** The immutable security firewall. Intercepts incoming chat payloads and runs heuristics to block prompt injections and role-play hijacking. Auto-updates its threat matrix via simulated cron jobs.
- **`POST /api/agents/architect` (Agent 01 - The Architect):** Interrogates the lead, probes for constraints, and synthesizes the final Executive Report.
- **`POST /api/agents/finance` (Agent 02 - The Financial Engineer):** Ingests the Executive Report, calculates risk margins against base pricing, and auto-generates the $1M+ SOW.
- **`POST /api/agents/ops` (Agent 03 - The Operations Dispatcher):** Scans the partner network and dispatches SMS alerts to architects with a strict 30-minute SLA timeout.

### 3. Zero-Trust File Security & Client Previews
- **`POST /api/upload` (Ingestion API):** A rigorous ingestion pipeline that rejects any file exceeding 5MB, strictly validates MIME types (PDF, DOCX only), and simulates a malware heuristic scan.
- **`/preview/[leadId]` (Isolated Portal):** A secure, AES-256-GCM styled terminal interface where clients must enter a 4-digit PIN (generated by the Admin OS) to decrypt and view their SOW.

## 🔌 Wiring External Systems (Integration Guide)

When wiring external systems (CRMs, Payment Gateways, Mail Servers), use the following anchor points:

### 1. Payment Gateways (e.g., Stripe, M-Pesa Daraja)
- **Anchor:** `/api/checkout/route.ts`
- **Integration:** Hook into the SOW acceptance button in `/preview/[leadId]`. Pass the `total_investment` calculated by Agent 02 into your payment intent generator.

### 2. Mail & SMS Servers (e.g., Resend, Twilio)
- **Anchor:** `/api/agents/ops/route.ts`
- **Integration:** Replace the `console.log` simulated SMS dispatch with your actual Twilio SDK. Pass the `sow_payload` details to notify partners.

### 3. CRM Integration (e.g., Salesforce, HubSpot)
- **Anchor:** `/api/inquiry/route.ts` and `src/app/admin/page.tsx`
- **Integration:** Currently, leads are stored in Prisma (`Lead`, `ServiceBlueprint`). When a lead reaches `READY_FOR_PREVIEW` status, set up a Prisma middleware or webhook to sync the data to your external CRM.

## 🚀 Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Database Setup (Prisma):**
   ```bash
   set NODE_TLS_REJECT_UNAUTHORIZED=0
   npx prisma generate
   npx prisma db push
   ```

3. **Run the Development Server:**
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` to access the main portal.
5. Open `http://localhost:3000/admin` to access the Admin OS.
